# 💎 JLJoias - E-commerce de Joias Masculinas de Luxo

> Aplicação web de e-commerce desenvolvida com Next.js (App Router), TypeScript e Tailwind CSS, focada em alta performance, usabilidade responsiva e estética premium.

---

## 🚀 Tecnologias Utilizadas

- **Framework**: Next.js (App Router)
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS
- **Ícones**: Lucide React
- **Arquitetura**: Componentes Reutilizáveis & Rotas Dinâmicas (SSR/Client Components)

---

## ✨ Funcionalidades Principais

- 📱 **Interface 100% Responsiva**: Adaptada para Mobile, Tablet e Desktop.
- 🛍️ **Home Page Interativa**: Hero Banner, vitrine de destaques e carrosséis de produtos.
- 💎 **Página de Produto Dinâmica (`/produto/[id]`)**:
    - Galeria de imagens interativa com suporte a miniaturas.
    - Seletor de tamanhos com atualização em tempo real.
    - Opção de compra instantânea via WhatsApp.
- 🛒 **Carrinho Lateral (*Cart Drawer*)**:
    - Acesso rápido sem troca de página.
    - Cálculo automático de subtotal e desconto no PIX (5%).
- 🔒 **Checkout Simulado (`/checkout`)**:
    - Formulário completo de dados e endereço.
    - Alternância dinâmica entre pagamento via PIX e Cartão de Crédito.
    - Tela de confirmação de pedido finalizado.
